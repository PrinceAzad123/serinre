# Sereni-Tea 🍵

> Premium artisan tea online shop with an interactive AI tea sommelier, responsive UI, shopping cart, and 3-step checkout.

## ✨ Features

- **Curated Tea Menu:** 16 specialty teas across Green, Black, Herbal, Oolong, and Specialty categories.
- **AI Tea Sommelier:** Chat assistant recommending teas based on moods, health benefits, caffeine preferences, and brewing tips.
- **Interactive Shopping Cart:** Real-time quantity adjustments, cart totals, and automatic free shipping calculator ($50+).
- **3-Step Checkout:** Details, delivery preferences, and live order summary with generated order IDs.
- **Zero Dependencies:** Pure vanilla HTML5, CSS3 (BEM layout), and modular ES6 JavaScript.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser. No server or build setup required!

```bash
# Clone the repository
git clone https://github.com/PrinceAzad123/serinre.git

# Open the project
cd serinre
start index.html
```
